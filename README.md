## О проекте

**FamilyPulse** — мобильное приложение для бережного контроля экранного времени, интернет-безопасности и связи между родителями и детьми. Единая кодовая база объединяет полноценный родительский кабинет управления и защищённый детский рабочий экран (Home Launcher).

Проект построен на современном нативном стеке Android (AGP 9.1.1 + Built-in Kotlin + Gradle 9.3.1) с использованием системных API (`UsageStatsManager`, `AccessibilityService`, `DevicePolicyManager`, `VpnService`) и адаптирован под особенности фирменных прошивок Android (включая EMUI / HarmonyOS на устройствах Huawei и Honor).

## Ключевой функционал и возможности

* **Два режима работы в одном APK:** выбор роли при первом запуске (**Родитель** или **Ребёнок**) и быстрая привязка устройства по семейному коду / QR.
* **Кастомный прозрачный детский лаунчер (Home Launcher):**
  * Отображение поверх системных обоев устройства (`TransparencyMode.transparent`).
  * Свободная сетка ярлыков `4×5` с поддержкой перетаскивания (drag-and-drop) между рабочим столом и доком, а также меню приложений по свайпу вверх.
  * Настраиваемый нижний док до 5 слотов с подтягиванием системной иконки звонилки и быстрой заменой ярлыков.
  * Верхний информационный виджет с аватаркой ребёнка, счётчиками активных заданий и непрочитанных сообщений, а также скрытым входом в родительское меню по долгому нажатию.
* **Контроль экранного времени и блокировка приложений:**
  * Точный учёт времени использования приложений через Android `UsageStatsManager`.
  * Индивидуальные лимиты, расписания и ночной режим.
  * Мгновенное перекрытие заблокированных или исчерпавших лимит приложений экраном `BlockedAppActivity` с возможностью отправить родителю запрос на разблокировку.
* **Многоуровневая защита от обхода и удаления:**
  * Контроль системных окон через `AccessibilityService` (предотвращение сброса разрешений в настройках устройства).
  * Защита от удаления приложения через `DeviceAdminReceiver`.
  * Временный родительский доступ к системным настройкам по паролю (режим обхода на 5 минут).
* **Локальная DNS-фильтрация (VPN):** встроенный локальный `VpnService` на устройстве ребёнка для фильтрации нежелательных сайтов и доменов по чёрным/белым спискам без пропускания трафика через сторонние серверы.
* **Геолокация, геозоны и история маршрутов:**
  * Отображение актуального местоположения ребёнка, точности GPS, скорости движения и уровня заряда батареи на растровой карте (2ГИС / ArcGIS через `flutter_map`).
  * Настройка геозон («Дом», «Школа», «Секция») с автоматическими уведомлениями о входе/выходе и стабилизацией координат внутри зоны.
  * История перемещений за последние 14 дней с фильтрацией GPS-выбросов и объединением стоянок.
* **Семейный чат и система заданий:** общий чат семьи с системными уведомлениями о событиях безопасности, поручения с наградами и календарь.
* **Автообновление через GitHub Releases:** встроенный сервис `GitHubUpdateService` для проверки, загрузки и установки новых версий APK напрямую из релизов репозитория.

## Поддержка платформы

* **Целевая платформа:** Android 7.0 (API 24) и выше.
* **Оптимизация под оболочки:** протестировано и адаптировано для устройств Samsung (One UI), Xiaomi/Redmi/POCO (MIUI / HyperOS), а также Huawei и Honor (EMUI / HarmonyOS), включая корректную работу фоновых служб, автозапуска и системных иконок.
* **Необходимые системные разрешения (на устройстве ребёнка):**
  * Статистика использования (`PACKAGE_USAGE_STATS`) — для учёта экранного времени.
  * Поверх других окон (`SYSTEM_ALERT_WINDOW`) — для экрана блокировки приложений.
  * Служба доступности (`AccessibilityService`) и Администратор устройства (`DeviceAdmin`) — для защиты от обхода ограничений и удаления.
  * Геолокация в фоновом режиме (`ACCESS_FINE_LOCATION`, `ACCESS_BACKGROUND_LOCATION`) и исключение из оптимизации батареи.
  * Локальный VPN (`BIND_VPN_SERVICE`) — при включении веб-фильтра.

## Инструкция по установке и запуску

### Установка готового APK (для пользователей)

1. Перейдите в раздел **Releases** репозитория на GitHub и скачайте актуальный файл `app-release.apk`.
2. Установите APK на смартфоны родителя и ребёнка (при необходимости разрешите установку из неизвестных источников).
3. На устройстве родителя выберите роль **«Родитель»**, создайте профиль семьи и сгенерируйте код / QR для привязки.
4. На устройстве ребёнка выберите роль **«Ребёнок»**, отсканируйте код привязки и последовательно выдайте запрашиваемые системные разрешения на экране настройки, после чего выберите **FamilyPulse** в качестве рабочего экрана (лаунчера) по умолчанию.
